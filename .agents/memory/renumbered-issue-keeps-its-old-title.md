# Check renumbered issue titles

This note helps contributors keep issue filenames and titles consistent after renumbering.

Check the filename, title, and register references after renumbering an existing issue.
Match the reStructuredText heading markers to the title length.
The register reads metadata and filenames, so a successful build does not prove the title contains the correct number.
Read [docs/issues/README.rst](../../docs/issues/README.rst), "Metadata fields", for record conventions.
