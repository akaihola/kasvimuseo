# Use synthetic examples in public records

This note helps contributors keep installation data out of public issue records and fixtures.

Describe an application behavior with a synthetic example, not with counts, identifiers, or names from the installation.
The private `kasvimuseo-deployment` repository owns the original evidence, in `docs/public-issue-evidence.rst`.
Write "a restored copy of the installation" when a check used the production database, and keep the numbers private.
Use the project's synthetic plant names, such as `valkonarsissi` and `tarhapioni`, and synthetic people, such as `puutarhuri`.
Keep author credits, copyright notices, and upstream attribution; task 7 lists the notice files.
