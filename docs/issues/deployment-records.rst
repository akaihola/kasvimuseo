==================
Deployment records
==================

This page helps contributors recognise issue numbers that the private deployment repository owns.
Issue numbers are never reused, so the register keeps these numbers reserved without files.

The public register once held a placeholder file for each number below.
Task 8 removed the placeholders on 2026-10-11, because they recorded nothing a contributor could act on.
The private ``kasvimuseo-deployment`` repository owns the report, the evidence, and the decision of each record.

The ``Depends on``, ``Blocks``, and ``Related`` fields of public issues name public issues only.
