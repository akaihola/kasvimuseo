Kylttien tulostus
-----------------

Osoite: https://kasvit.ambitone.com/kasvimuseo/planting-labels/

Ohjeita:

- siirrä istutus omalle kyltille:

- raahaa hiirellä numero ulos kyltistä

- yhdistä istutus takaisin yhteiselle kyltille:

- raahaa hiirellä numero takaisin alkuperäiseen kylttiin

- vaihda kuvaa:

- käytä kuvan vasemmassa ja oikeassa yläkulmassa olevia nuolia

- piilota kyltti tulosteesta:

- poista tulostusrasti kyltin oikeassa alalaidassa

- talleta muutokset:

- napsauta “Save changes” -painiketta sivun ylälaidassa

Kasvien luokittelun kentät
--------------------------

Kentät tällä hetkellä:

- genus / sukunimi

- species / laji

- group / ryhmä

- subspecies

- variety / lajike
